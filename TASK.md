Build a small TypeScript Node CLI (zero runtime deps, node:test tests, MIT LICENSE, English README with usage) for ISO 281 basic rolling bearing rating life: inputs dynamic load rating C (kN), equivalent load P (kN), type ball (p=3) or roller (p=10/3), optional speed rpm, optional reliability factor a1 (default 1, table for 90/95/96/97/98/99% = 1/0.64/0.55/0.47/0.37/0.25). Output L10 in million revolutions = a1*(C/P)^p and hours = L10*1e6/(60*rpm), plus --json. Validate inputs (exit 1 with message). Example: C=14 P=2 ball rpm 1500 → L10=343 Mrev, ≈3811.1 h. package.json scripts build (tsc) and test. Add .gitignore (node_modules, dist, *.log). Keep all writes inside this directory.
